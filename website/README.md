# Website pages

The student portal and Careers now live in the sibling `jpII-portal` directory. The original public URLs redirect there. Serve the repository root to make both directories available together.

All pages use the footer generated by `scripts/sync-site-chrome.mjs`, including department Quick Links and contact details taken from the contact page. Run `node scripts/sync-site-chrome.mjs` from the repository root after changing that template. Careers and Portal are available through footer Resources, not the public main navigation.

Open `index.html` for a basic local view, or serve the repository root with a static web server to include the portal. For Vercel, run `npm run build` from the repository root; see `../DEPLOYMENT.md` for the deployment settings.

- `assets/pages/programs.html`: department directory, preserving the existing entry point.
- `assets/pages/film.html`, `solar.html`, `music.html`, `it.html`: dedicated department pages.
- `assets/pages/inquiries.html`: shared course customization form.
- `assets/css/site.css`: shared navigation and department/form design, responsive layouts, dark theme, and reduced-motion support.
- `assets/js/site.js`: desktop hover disclosure, mobile accordion/menu, keyboard dismissal, and theme preference.
- `assets/js/inquiries.js`: department/course prefill, input validation, email draft preparation, and text download.

The form uses `admissions@jp2tvet.edu.et`, taken from the existing contact page. It opens an email draft for the visitor to review and send; it does not submit to a server. The downloadable text copy provides a fallback when no email client is configured. Confirm the admissions address before release. Direct delivery and persistent records require a backend integration.

Department pages use standalone CSS and JavaScript, with Public Sans from Google Fonts and a system font fallback. Existing pages retain their Tailwind CDN dependency. Navigation markup is present in each HTML file so department links do not rely on JavaScript rendering; keep it synchronized when adding future pages.

From the repository root, run `node check-website.mjs` for local link, navigation, and course coverage checks, and `node --check website/assets/js/site.js` / `node --check website/assets/js/inquiries.js` for syntax checks.
